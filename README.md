# CookSmart Backend API

API para búsqueda de recetas en español con información nutricional, conectada a TheMealDB.

## 🚀 Requisitos Previos

- Java JDK 17+
- Gradle 8.0+
- PostgreSQL (opcional para futuras versiones)

## ⚙️ Configuración Inicial

1. Clona el repositorio:
```bash
https://github.com/jayelsea/Integrate-Proyect.git
cd cooksmart-backend
# Verificar Java
java -version
```
## 2. Verificacion de versiones

# Verificar Gradle (si está instalado globalmente)
```bash
gradle -version
```
# El proyecto incluye Gradle Wrapper, así que también puedes usar:
```bash
./gradlew -version  # En Linux/Mac
gradlew.bat -version  # En Windows
```
# Usando Gradle Wrapper
```bash
./gradlew build
```

# Gradle instalado globalmente
```bash
gradle build
```
